# Andy 个人官网全新设计方案

版本：2026-10-07。基于现有素材库和经历文案制定；本文件为设计提案，不代表已经实现或完成视觉验证。

## 1. 核心方向

设计主题：**穿行于科技品牌之间 / Through Technology**。

把网站做成一部可以通过滚动探索的个人作品集。Andy 是贯穿全站的主角，光轮智能、轻舟智航、Momenta、极氪、小米是五个视觉章节。每章通过实际素材、品牌色、构图和运动方式建立自己的性格，再用连续的滚动过渡串起来。

首要观众是招聘负责人、科技品牌团队与潜在合作方。进入页面几秒内知道 Andy 是谁、擅长什么；快速浏览能看到代表成果；愿意深入的人可以打开案例、播放视频并访问项目原文。

原有暗房、胶片齿孔、Frame 编号、红色尘埃、镜头炫光、CRT 故障、模拟终端、快门音效及左侧固定侧栏全部退出新视觉系统。现有真实内容、双语能力和适用的技术基础继续服务新设计。

## 2. 页面结构与节奏

| 顺序 | 章节 | 内容重点 | 视觉与篇幅 |
| --- | --- | --- | --- |
| 01 | Andy 开场 | 姓名、定位、精选作品入口 | 全幅影像，约一屏，底部露出下一章 |
| 02 | 光轮智能 | RoboStack、持续学习系统、WRC 品牌项目 | 重点长章，机器人与仿真影像 |
| 03 | 轻舟智航 | 官网从零搭建、品牌传播、车展参与 | 重点长章，绿色道路与官网案例 |
| 04 | Momenta | 内容运营、KOC、WICV 传播 | 中等章节，蓝色路径与真实传播案例 |
| 05 | 极氪 | 用户增长、线下活动、获客成果 | 短章，黑白金属与车辆横向运动 |
| 06 | 小米之家 | 销售、产品陈列与门店体验 | 短章，明亮产品画面与橙色点缀 |
| 07 | 个人视角 | 精选摄影、个人简介、早期经历 | 安静的摄影版面，恢复自然滚动 |
| 08 | 联系 | 邮件、GitHub、合作方向 | 简短明确，形成落点 |

篇幅按案例内容决定。光轮、轻舟合计占主要作品内容约一半；极氪、小米每章只保留一个主画面、一段角色说明和两三个关键成果，避免五章等长造成疲劳。

顶部固定导航：Andy、作品、关于、联系、语言切换。作品入口展开五个品牌的文字目录，可直接跳转。桌面右侧采用纤细进度线与当前品牌名称；移动端只保留紧凑导航。无需按顺序看完才能访问任何内容。

## 3. 统一视觉规则

- 全站统一字体、排版网格、按钮与案例详情结构；章节自行改变背景明暗、强调色、画面布局与运动方向。
- 中性基础色采用纸白、炭黑与中性灰。五个品牌色分别出现在自己的章节，避免整站被单一色系覆盖。
- 字体建议使用 Source Sans 3 搭配 Noto Sans SC；正文清晰克制，标题使用有力度的无衬线字重。技术感主要来自真实内容与空间运动。
- Hero 的主标题为 **Andy**。支持文案沿用“让硬核科技被看见、理解、记住”，下方标注品牌传播、影像创作、数字体验。
- 桌面 Hero 姓名建议 112–144px，移动端 56–72px；章节标题桌面 48–64px、移动端 32–40px。通过明确断点切换固定字号，不用随视口连续缩放的字号，不设负字距。
- 真实图片、视频直接铺满画面或进入无边框网格。页面章节不包在悬浮卡片中；项目列表使用分隔线、标题、缩略图和明确入口。
- 品牌 Logo 保持原比例、颜色、净空和清晰度。用位置、遮罩、淡入产生动效，不拉伸、拆解或重绘标识。Momenta 现有 PNG 适合正常标识尺寸，不作为巨型全屏 Logo。
- 每章首个可见区域同时出现品牌、职位与时间，避免只看见企业宣传而找不到个人身份。
- 主要文字排在影像留白或独立文字区；确需叠字时局部提高对比，保持产品主体清晰。

## 4. 首屏：先记住 Andy

首屏采用全幅真实影像背景，姓名与定位直接叠在画面上，不做左右分栏或装饰容器。优先从用户提供的 RoboStack、持续学习视频中筛出清晰、无密集字幕、能辨认真实对象的短片段，作为初始背景；如果没有合适片段，使用清晰抽帧静态海报并保留轻微视差。

初次入场：背景先显示，Andy 与定位随后在约 0.6–0.9 秒内出现。首屏不设置加载倒计时或阻塞式品牌动画。提供“查看作品”和“联系”两个明确入口，背景视频配暂停按钮。

首屏高度按可用视口扣除导航及约 64–96px 的下一章预告区设计，宽屏与手机都能看到下一章的一部分。品牌目录位于预告区，使用简洁名称和小尺寸真实 Logo，表达职业经历。

不默认自动轮播五家企业，不让正在阅读的背景频繁跳变。进入正文后，滚动决定各品牌画面的出现。

## 5. 五个品牌章节

### 光轮智能：实体与仿真

气质：精密、空间感、真实机器人与仿真世界的对应。颜色遵循已有《光轮智能 BRANDguidelines 2026.pdf》，实施前读取其色值与 Logo 规范；本方案不猜测具体品牌色。

以 `RoboStack成都.mp4`、`持续学习final.mp4` 为主，优先选择可辨认的机器人、工作环境和仿真场景。章节展开时，影像在全幅范围内切换两个相关画面，通过统一遮罩边缘保持连续感。辅助标线只用于强调实际对象与案例结构，不伪造识别框或技术指标。

正文用三个无边框项目条目承载：RoboStack 产品部署视频、持续学习系统介绍视频、WRC2026 品牌项目。突出已有文案中的脚本、拍摄、后期及统筹职责。WRC 目录的开源数据集视频标注为发布内容，不充当展台现场视频。

只保留一个短距离的粘性影像舞台，滚动经过“作品画面 → 我的职责 → 项目入口”三个状态，随后恢复自然流动。

### 轻舟智航：沿着道路进入作品

气质：开放、流动、清晰的科技感。主色 **#15CC8A**，与白色、石墨灰组合；浅绿只作局部背景。

以 `home/hero-web.jpg` 的绿色道路与汽车为章节主视觉。道路方向引导视线，绿色路径沿其走势逐步显现，车辆主体保持完整。主案例是“从零搭建轻舟官网”，采用真实网站截图或录屏展示成果；截图在实施时从实际网站制作，不伪造界面。

下方连接小红书运营与车展传播：3 天涨粉 500+、官网上线、参与相关活动。现有车展照片用在对应项目处，日期与活动名称未确认的图片不强行归档。

技术多摄像头视频、带字幕路测视频放在可点播的案例详情中，保留其解释内容，避免大幅裁切成难以理解的背景。

### Momenta：路径与传播

气质：理性、清晰、具有方向性。采用 Logo 蓝参考 **#0068DF**，以白色、浅灰为主要底色，局部深色道路画面形成对比。

主视觉采用 `mpilot-desktop.jpg` 完整智驾车辆图，蓝色细线随滚动延伸，连接“内容运营 → 账号孵化 → 活动传播”三个内容节点。节点对应实际工作内容，不画成未经证实的智驾技术架构。

将 100+ 篇内容、10+ KOC 与 3000 万曝光并列呈现，保留原经历口径与相关活动语境，不把团队活动曝光改写成个人独立创造。重点案例使用 WICV 原文入口与已有采访图。

官网技术动画含字幕与品牌信息，作为可播放的官方补充素材；个人案例与官方产品示意分别标注。

### 极氪：速度与金属

气质：克制、高对比、车辆本身有冲击力。以黑、白、金属灰为主要配色，不自行认定新的极氪品牌强调色。

使用 `zeekr-001.jpg` 的完整车辆和场景作为主图，利用图片在容器内的轻微横向位移表达动势。车身细节图只用于章节边缘的短暂过渡，不以无法辨认的局部替代主视觉。

文字区域呈现用户增长、20+ 场活动与五一车展获客结果。数字随内容一次出现即可，不循环滚动，也不以速度仪表样式夸大成果。80000+ 用户、5000+ 获客等详细口径在案例内容中沿用原文。

不强制把整个章节改成横向滚动，访客仍使用正常纵向阅读。

### 小米之家：产品与生活

气质：明亮、简洁、有亲和力。以白色、浅灰和 **#FF6900** 橙色点缀构成，与上一章产生明显明暗切换。

主图优先采用 `xiaomi-15-hero.webp`，辅助用 `xiaomi-personal-devices.jpg` 和 `xiaomi-smart-home.jpg`。手机近景进入画面后，产品组合轻微错位展开，配合角色说明与销售成果。用现有完整图片做位移和遮罩，不为复杂分层强行抠图。

内容聚焦产品陈列、库存与销售：国补期间单日最高 20+ 单、成交额 2 万+。采用原始含义，不将成交额描述为任职期间累计或日均。

汽车素材仅作备用。国际站产品图片与 2026 About 视觉作为品牌配图，不暗示就是实习门店当时的型号或本人拍摄的门店照片。

## 6. 品牌之间如何过渡

转场采用“当前画面的构图引导下一个画面”，由滚动进度控制正反播放。以下为动效设计意图，具体遮罩形状由实际选帧和裁切决定。

| 边界 | 主要动作 | 连续关系 |
| --- | --- | --- |
| 开场 → 光轮 | 开场文字离场，影像在同一位置延续，品牌与职责进入 | 同一素材建立空间连续性 |
| 光轮 → 轻舟 | 影像收束到横向窗口，道路图从同一窗口扩展，绿色进入界面 | 从机器人工作环境进入道路场景 |
| 轻舟 → Momenta | 道路引导线延伸为蓝色路径，背景由浅绿自然切换为白色 | 同一方向的路径承接两个智驾品牌 |
| Momenta → 极氪 | 蓝线滑出，画面遮罩沿车辆运动方向打开，进入黑白金属空间 | 用运动方向承接，色彩短暂退场 |
| 极氪 → 小米 | 车辆高光与浅色产品背景交接，画面逐步变亮，橙色标识进入 | 利用亮度和材质过渡，不使用闪白 |
| 小米 → 摄影 | 产品画面向上退出，摄影网格与文字自然进入 | 减少运动，让个人作品获得观看时间 |

每个边界集中表现一个主要动作，避免同时叠加旋转、模糊、粒子爆炸和页面缩放。桌面转场滚动距离初拟 35–60vh，实际依素材与阅读测试调整；移动端缩短为轻量揭示。

全屏高冲击效果集中在开场、光轮舞台和一两处关键转场，其余内容保证可阅读。文字在主要运动结束后保持稳定，不持续跟随鼠标漂移。不修改系统光标，不默认开启音效。

## 7. 项目详情与个人内容

案例通过明确的“查看项目”入口展开独立详情层，桌面为大幅对话框、移动端为全屏详情。支持独立 URL hash 或等价的可分享定位、浏览器返回、Escape 关闭、焦点管理，关闭后回到原章节位置。

详情结构统一为：项目名称与时间、本人角色、工作内容、成果与上下文、图片或视频、项目原文。已有内容缺少的流程说明不自行编造，采用简洁版详情即可。

个人摄影选 6–8 张做有节奏的无边框网格，点击看大图。当前 800px 图适用于网格，不放大成模糊的桌面全屏背景。之后只为确实选中的大图补高清源片。

关于区域用短文串起品牌传播、影像、官网搭建三项能力。陕西电视台与西北大学只保留紧凑的两行经历，按用户要求不另设品牌章节。

联系区域提供真实邮件与 GitHub，复制邮箱有明确反馈。不出现未提供地址的占位社交链接，也不把构建技术作为主要页面文案。

## 8. 移动端与无障碍

- 移动端围绕画面主体重新裁切，不按桌面比例直接缩小；手机主图、车辆与 Logo 都需完整可辨。
- 取消长距离粘性叙事和复杂空间旋转，以自然滚动、短距离位移、淡入和局部遮罩保留章节特色。
- 按钮与图标有足够点击区域；菜单、视频、详情和语言切换均可键盘操作。陌生图标提供可访问名称与必要提示。
- 页面提供跳过导航、明确标题层级；正文对比度至少 4.5:1。品牌原色不一定适合小字，正文使用合适的中性色。
- `prefers-reduced-motion` 下直接展示最终状态，关闭粘性舞台、视差、自动播放与过渡扭曲。内容和链接保持完整。
- 视频自动播放失败、节流或加载失败时呈现清晰海报与播放入口；真实内容不会因动画初始化失败而不可见。
- 中英双语继续集中维护。默认英文沿用现有设置，允许一键切换；中文与英文分别检查排版、换行和定位。

## 9. 技术与素材实施方案

继续使用 React、Vite、Tailwind、GSAP ScrollTrigger 和现有适用的滚动基础。新章节以实际 DOM 位置决定导航状态，不再使用原来的固定全页百分比阈值。

首版主要效果使用图片、视频、CSS 遮罩和 GSAP。仅当一个明确的空间效果确实需要 3D 时再引入局部 Three.js 场景，不保留旧全站粒子背景。动画统一处理创建、清理、视口变化、字体加载及降级，兼容 React StrictMode。

现有素材目录保留为原始资料库。选用资源另行生成 WebP/AVIF、视频短片、静态封面与移动端裁切，进入 `client/public` 的新版专用目录，同时保留可追溯的来源记录。

加载策略：优先显示首屏海报和文字，视频随后加载；屏幕外视频暂停，仅活动章节播放，下一章按需预加载，其他章节懒加载。原始长视频与 7000px 大图不直接进入页面首载。

初步优化目标：首屏关键传输资源约 1.5MB 以内，短循环视频单段约 1–3MB，移动端普通主图约 150–350KB。这些是待实测调整的设计预算，不是已达成的结果。慢网络优先海报，不能为预算损坏关键画面质量。

性能验收以真实构建为准：LCP 目标 ≤2.5 秒、CLS ≤0.1，滚动过程避免持续丢帧；桌面和移动端分别测量。不会为了追求复杂特效阻塞正文与操作。

## 10. 制作顺序与验收

1. 建立全新视觉样稿：先做 Andy 首屏、光轮和轻舟两章及它们之间的过渡，同时验证桌面和手机。此阶段确定共同字体、导航、画面比例与动画节奏。
2. 扩展五品牌叙事：完成 Momenta、极氪、小米章节，让明暗与配色的变化构成全站节奏，避免复用同一模板只换颜色。
3. 补齐内容闭环：案例详情、摄影、关于、联系、双语、分享定位与返回行为。
4. 完成资源优化及验证：lint、生产构建、桌面和手机浏览器检查、reduced-motion、键盘访问、视频失败状态与慢网络。

视觉验收重点：第一屏明确是 Andy 的网站；每个品牌具有可识别的不同风格；每章能看见本人角色和成果；真实素材主体清晰；转场自然且可跳过；所有尺寸没有文字溢出、内容遮挡或横向溢出；移动端不出现过长空白或滚动卡住。

现有素材足够开始上述工作。品牌手册的精确色值读取、视频选段、截图制作和网页压缩属于实施环节，不需要用户再做一轮普遍性素材收集。
