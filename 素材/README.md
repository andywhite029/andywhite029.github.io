## 放置方式

- 品牌资料：官方 Logo（优先 SVG 或透明 PNG）、品牌手册、品牌色值、官网参考链接。
- 项目目录：照片、视频、封面，以及项目说明或公开链接。
- 个人目录：摄影作品、拍摄或工作现场照片。
- 暂时不确定分类的素材，可以直接放在对应公司的目录下。

品牌色值和链接可以写在自己新建的文本文件中，不清楚的内容留空即可。
每个项目可附一份说明，填写以下信息：

```text
项目：
我的职位与时间：
我具体负责：
最想展示的成果：
优先使用的图片或视频：
公开链接：
素材限制（是否可公开、是否需署名、是否需要遮挡信息）：
品牌色或品牌规范：
```

## 存储说明

本目录用于本地收集原始素材，不参与网站构建和部署。
除本说明和用于保留空目录的 .gitkeep 外，所有内容默认被 Git 忽略，
包括图片、视频、Logo、设计源文件和项目说明，不会随普通 Git 提交上传。
Git 不会备份这些素材，请保留原始文件的备份。

后续筛选与压缩后的网页资源会另行放入 client/public，本目录中的原始素材保留。
